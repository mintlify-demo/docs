{user.name ? <>Welcome back, <strong>{user.name}</strong>{user.plan ? <> (<strong>{user.plan}</strong> plan)</> : null}.</> : null} The Merge Sort API is a small FastAPI service with three endpoints. One gives you a sorted list. Another shows you **how** the list got sorted. The third times several sorting algorithms on the same list so you can compare them.

<Note>
  This API is a demo. Its code lives in the [merge-sort-api repository](https://github.com/mintlify-demo/merge-sort-api), and these docs live in the [docs repository](https://github.com/mintlify-demo/docs/tree/main/merge-sort-api).

## Compare algorithm timings

Call `/sort/stats` when you want to see which algorithm is fastest for a given input. It accepts the same body as `/sort`. The API sorts your list with quick sort, merge sort, and heap sort, and times each one on the server.

```bash
curl -X POST http://localhost:8000/sort/stats \
  -H "Content-Type: application/json" \
  -d '{"numbers": [5, 2, 9, 1, 5, 6], "order": "asc"}'
```

The response lists every timing in milliseconds, fastest first, and names the winner in `fastest`:

```json
{
  "count": 6,
  "order": "asc",
  "result": [1, 2, 5, 5, 6, 9],
  "timings": [
    { "algorithm": "heap", "elapsed_ms": 0.0031 },
    { "algorithm": "merge", "elapsed_ms": 0.0062 },
    { "algorithm": "quick", "elapsed_ms": 0.0075 }
  ],
  "fastest": "heap"
}
```

Timings vary from run to run, so send the same list a few times before drawing conclusions.
