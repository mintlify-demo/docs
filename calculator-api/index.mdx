## Versions

| Version | Shape | Use it when |
| --- | --- | --- |
| **v1** (deprecated) | `POST /v1/add`, `/v1/subtract`, `/v1/multiply`, `/v1/divide` with `{a, b}` | You maintain an existing integration and haven't migrated yet |
| **v2** | `POST /v2/calculate` with `{operation, operands}` | You're building something new, have two or more numbers, or need `power` or `modulo` |

<Warning>
  v1 is deprecated and will be removed on **January 31, 2027**. The v1 endpoints keep working until then. Use v2 for new integrations, and move existing calls to `POST /v2/calculate` before that date. See [migrating from v1 to v2](/calculator-api/guides/v1-vs-v2#migrating-from-v1-to-v2).
</Warning>
