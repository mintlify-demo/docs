<Warning>
  v1 is deprecated and will be removed on **January 31, 2027**. All four v1 endpoints keep working until then. Migrate to `POST /v2/calculate` before that date.
</Warning>

You're reading the docs for **v1**, the original Calculator API. For `POST /v2/calculate`, switch to **v2** in the version switcher at the top of the sidebar.

| Endpoint | Body | Returns |
| --- | --- | --- |
| `POST /v1/add` | `{"a": 12, "b": 4}` | `{"result": 16}` |
| `POST /v1/subtract` | `{"a": 12, "b": 4}` | `{"result": 8}` |
| `POST /v1/multiply` | `{"a": 12, "b": 4}` | `{"result": 48}` |
| `POST /v1/divide` | `{"a": 12, "b": 4}` | `{"result": 3}`, or `400` when `b` is `0` |

```bash
curl -X POST http://localhost:8000/v1/add \
  -H "Content-Type: application/json" \
  -d '{"a": 12, "b": 4}'
```

<Tip>
  See [migrating from v1 to v2](/calculator-api/guides/v1-vs-v2#migrating-from-v1-to-v2) for each v1 endpoint's v2 equivalent.
</Tip>
