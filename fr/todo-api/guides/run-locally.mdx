Exécutez la Todo API sur votre propre machine pour tester vos modifications avant d'appeler l'API hébergée.

## Démarrer le serveur {#start-the-server}

<Steps>
  <Step title="Installer les dépendances">
    ```bash
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Démarrer le serveur">
    ```bash
    uvicorn main:app --reload
    ```
    Le serveur écoute sur le port `8080`.
  </Step>
  <Step title="Vérifier qu'il fonctionne">
    ```bash
    curl http://localhost:8080/todos -H "X-API-Key: demo-key"
    ```
  </Step>
</Steps>

<Tip>
  Utilisez la clé d'API `demo-key` pendant vos tests. Consultez [Authentification](/fr/todo-api/guides/authentication) pour les autres clés de démonstration.
</Tip>
