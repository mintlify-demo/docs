Exécutez la Todo API sur votre propre machine pour tester vos modifications avant d'appeler l'API hébergée.

## Démarrer le serveur {#start-the-server}

<Steps>
  <Step title="Installez les dépendances">
    ```bash
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Démarrez le serveur">
    ```bash
    python serve.py
    ```
    Le serveur écoute sur `127.0.0.1`, sur le port `8000`, et se recharge lorsque vous modifiez le code. Pour utiliser un autre port, définissez `PORT` :
    ```bash
    PORT=9000 python serve.py
    ```
    Définissez `HOST` pour écouter sur une autre interface. `uvicorn main:app --reload` démarre aussi le serveur sur le port `8000`.
  </Step>
  <Step title="Vérifiez qu'il est en cours d'exécution">
    ```bash
    curl http://localhost:8000/todos -H "X-API-Key: demo-key"
    ```
  </Step>
</Steps>

<Tip>
  Utilisez la clé d'API `demo-key` pendant vos tests. Consultez [Authentification](/fr/todo-api/guides/authentication) pour les autres clés de démo.
</Tip>
