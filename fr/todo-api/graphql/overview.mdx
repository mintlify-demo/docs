L'API Todo parle aussi GraphQL sur `/graphql`. Elle lit et écrit les mêmes tâches que l'API REST : une tâche créée ici apparaît donc dans `GET /todos` et dans le [flux d'événements](/fr/todo-api/events/overview).

Les pages de référence ci-dessous sont générées à partir de [`schema.graphql`](https://github.com/mintlify-demo/docs/blob/main/todo-api/schema.graphql), qui correspond au code serveur de [`todo_graphql.py`](https://github.com/mintlify-demo/todo-api/blob/main/todo_graphql.py). Quand le schéma change, la référence change avec lui.

## Envoyer une requête {#send-a-query}

Envoyez votre clé d'API dans l'en-tête `X-API-Key`, comme pour REST.

<CodeGroup>
```bash cURL
curl http://localhost:8000/graphql \
  -H "X-API-Key: demo-key" \
  -H "Content-Type: application/json" \
  -d '{"query": "{ todos(pageSize: 5) { total items { id title completed } } }"}'
```

```graphql Query
query {
  todos(pageSize: 5, completed: false) {
    total
    items { id title completed createdAt }
  }
}
```

```graphql Mutation
mutation {
  createTodo(input: { title: "Write the docs" }) {
    id
    title
  }
}
```
</CodeGroup>

<Tip>
  Avec l'API en cours d'exécution, ouvrez `http://localhost:8000/graphql` dans un navigateur pour accéder à GraphiQL. Ajoutez `{"X-API-Key": "demo-key"}` dans son panneau **Headers**.
</Tip>
