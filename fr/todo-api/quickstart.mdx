---
title: Démarrage rapide
description: Exécutez l'API Todo en local, puis créez, lisez et terminez une tâche.
icon: rocket
---

<Steps>
  <Step title="Installer et lancer">
    ```bash
    git clone https://github.com/mintlify-demo/todo-api.git
    cd todo-api
    python3 -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    uvicorn main:app --reload
    ```
  </Step>

  <Step title="Créer une tâche">
    Chaque requête nécessite l'en-tête `X-API-Key: demo-key`.

    <CodeGroup>
      ```bash cURL
      curl -X POST http://localhost:8000/todos \
        -H "X-API-Key: demo-key" \
        -H "Content-Type: application/json" \
        -d '{"title": "Write the docs"}'
      ```

      ```python Python
      import requests

      r = requests.post(
          "http://localhost:8000/todos",
          headers={"X-API-Key": "demo-key"},
          json={"title": "Write the docs"},
      )
      print(r.status_code, r.json())
      ```

      ```javascript JavaScript
      const res = await fetch("http://localhost:8000/todos", {
        method: "POST",
        headers: { "X-API-Key": "demo-key", "Content-Type": "application/json" },
        body: JSON.stringify({ title: "Write the docs" }),
      });
      console.log(res.status, await res.json());
      ```
    </CodeGroup>

    ```json Response (201)
    {
      "title": "Write the docs",
      "completed": false,
      "id": 1,
      "created_at": "2026-01-15T09:30:00Z"
    }
    ```
  </Step>

  <Step title="La marquer comme terminée">
    ```bash
    curl -X PATCH http://localhost:8000/todos/1 \
      -H "X-API-Key: demo-key" \
      -H "Content-Type: application/json" \
      -d '{"completed": true}'
    ```
  </Step>

  <Step title="Lister les tâches">
    ```bash
    curl "http://localhost:8000/todos?completed=true" -H "X-API-Key: demo-key"
    ```
  </Step>

  <Step title="Définir une date d'échéance">
    Ajoutez un `due_date` facultatif (AAAA-MM-JJ) lorsque vous créez ou modifiez une tâche. Envoyez `"due_date": null` pour le supprimer.

    ```bash
    curl -X POST http://localhost:8000/todos \
      -H "X-API-Key: demo-key" \
      -H "Content-Type: application/json" \
      -d '{"title": "File taxes", "due_date": "2026-04-15"}'
    ```

    Utilisez `overdue=true` pour lister les tâches non terminées dont la date d'échéance est antérieure à aujourd'hui (UTC).

    ```bash
    curl "http://localhost:8000/todos?overdue=true" -H "X-API-Key: demo-key"
    ```
  </Step>
</Steps>
