## Endpoints {#endpoints}

| Méthode | Chemin | Rôle |
| --- | --- | --- |
| `GET` | `/todos` | Lister les tâches (paginé, filtrable) |
| `POST` | `/todos` | Créer une tâche |
| `GET` | `/todos/{todo_id}` | Obtenir une tâche |
| `PATCH` | `/todos/{todo_id}` | Mettre à jour une tâche |
| `DELETE` | `/todos/{todo_id}` | Supprimer une tâche |
| `GET` | `/todos/list-all` | <Badge color="orange">Obsolète</Badge> Lister toutes les tâches, sans pagination |
| `POST` | `/todos/bulk` | <Badge color="purple">Enterprise</Badge> Créer jusqu'à 100 tâches en une fois |
| `POST` | `/graphql` | Requêtes et mutations GraphQL |
| `WS` | `/ws/events` | Flux de `todo.created`, `todo.updated`, `todo.deleted` |

<Warning>
  Les données sont stockées en mémoire. Redémarrer le serveur efface toutes les tâches.
</Warning>
