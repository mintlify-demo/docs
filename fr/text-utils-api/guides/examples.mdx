  <Tab title="Inverser">
    ```json Request to /reverse
    { "text": "stressed" }
    ```

  <Tab title="Nombre de mots">
    ```json Request to /word-count
    { "text": "Hello\nhello world" }
    ```

    ```json Response
    { "words": 3, "unique_words": 2, "characters": 17, "lines": 2 }
    ```

    <Note>
      `unique_words` ignore la casse : `Hello` et `hello` ne comptent donc qu'une fois.
    </Note>

## Mode palindrome strict {#strict-palindrome-mode}

Par défaut, `/palindrome` ignore la casse, les espaces et la ponctuation. Désactivez ce comportement avec `ignore_case_and_punctuation` :

<ParamField body="ignore_case_and_punctuation" type="boolean" default="true">
  Avec `false`, `Racecar` n'est **pas** un palindrome (R majuscule), mais `racecar` l'est.
</ParamField>

## Options de slug {#slug-options}

`/slugify` met le texte en minuscules, supprime les accents (`é` devient `e`), retire tout ce qui n'est ni une lettre ni un chiffre et relie les mots avec un séparateur. Utilisez-le pour créer des URL, des noms de fichiers ou des identifiants à partir de titres.

<ParamField body="separator" type="string" default="-">
  Caractère placé entre les mots. Utilisez `-` ou `_`. Toute autre valeur renvoie une `422`.
</ParamField>

<ParamField body="max_length" type="integer">
  Longueur maximale du slug, de `1` à `200`. Les slugs plus longs sont tronqués et tout séparateur final est supprimé.
</ParamField>

```json Request to /slugify
{ "text": "Hello, Mintlify Docs!", "separator": "_", "max_length": 15 }
```

```json Response
{ "original": "Hello, Mintlify Docs!", "slug": "hello_mintlify" }
```

<AccordionGroup>
  <Accordion title="Qu'est-ce qui compte comme un mot ?">
    Les suites de lettres, de chiffres, d'apostrophes et de traits d'union. `don't` et `well-known` comptent chacun pour un mot.
  </Accordion>
  <Accordion title="Quelle est la taille maximale ?">
    10 000 caractères par requête. Un texte plus long renvoie une `422`.
  </Accordion>
</AccordionGroup>
