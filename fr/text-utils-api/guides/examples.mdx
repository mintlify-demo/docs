<Tabs>
  <Tab title="Inverser">
    ```json Request to /reverse
    { "text": "stressed" }
    ```

    ```json Response
    { "original": "stressed", "reversed": "desserts" }
    ```
  </Tab>

  <Tab title="Nombre de mots">
    ```json Request to /word-count
    { "text": "Hello\nhello world" }
    ```

    ```json Response
    { "words": 3, "unique_words": 2, "characters": 17, "lines": 2 }
    ```

    <Note>
      `unique_words` ignore la casse : `Hello` et `hello` ne comptent donc qu'une fois.
    </Note>
  </Tab>

  <Tab title="Palindrome">
    ```json Request to /palindrome
    { "text": "Racecar" }
    ```

    ```json Response
    { "is_palindrome": true, "text": "Racecar" }
    ```
  </Tab>
</Tabs>

## Mode palindrome strict {#strict-palindrome-mode}

Par défaut, `/palindrome` ignore la casse, les espaces et la ponctuation. Désactivez ce comportement avec `ignore_case_and_punctuation` :

<ParamField body="ignore_case_and_punctuation" type="boolean" default="true">
  Avec `false`, `Racecar` n'est **pas** un palindrome (R majuscule), mais `racecar` l'est.
</ParamField>

<AccordionGroup>
  <Accordion title="Qu'est-ce qui compte comme un mot ?">
    Les suites de lettres, de chiffres, d'apostrophes et de traits d'union. `don't` et `well-known` comptent chacun pour un mot.
  </Accordion>
  <Accordion title="Quelle est la taille maximale ?">
    10 000 caractères par requête. Un texte plus long renvoie une `422`.
  </Accordion>
</AccordionGroup>
