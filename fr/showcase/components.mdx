## Diagrammes avec Mermaid

Écrivez un bloc `mermaid` et Mintlify le dessine, en mode clair comme en mode sombre.

```mermaid
sequenceDiagram
    participant Lecteur
    participant Docs as Docs Mintlify
    participant API as Votre API
    Lecteur->>Docs: Ouvre la page d'un endpoint
    Docs->>Lecteur: Affiche le générateur de requêtes et des exemples de code
    Lecteur->>API: Clique sur "Try it"
    API-->>Lecteur: 200 OK avec du JSON
```

Les organigrammes fonctionnent de la même façon.

```mermaid
flowchart LR
    Idée --> Brouillon --> Relecture --> Publication
    Relecture -- modifications demandées --> Brouillon
```
