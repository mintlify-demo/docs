## Encadrés {#callouts}

<Note>Une **note** ajoute du contexte supplémentaire.</Note>
<Tip>Un **conseil** partage un raccourci ou une bonne pratique.</Tip>
<Info>Un encadré **info** met en avant des informations de contexte utiles.</Info>
<Check>Une **validation** confirme une réussite.</Check>
<Warning>Un **avertissement** signale un point auquel faire attention.</Warning>
<Danger>Un encadré **danger** signale quelque chose qui peut tout casser.</Danger>

## Diagrammes avec Mermaid {#diagrams-with-mermaid}

Écrivez un bloc délimité `mermaid` et Mintlify l'affiche, en mode clair comme en mode sombre.

```mermaid
sequenceDiagram
    participant Reader as Lecteur
    participant Docs as Documentation Mintlify
    participant API as Votre API
    Reader->>Docs: Ouvre une page d'endpoint
    Docs->>Reader: Affiche le générateur de requêtes et les exemples de code
    Reader->>API: Clique sur "Try it"
    API-->>Reader: 200 OK avec du JSON
```

Les organigrammes fonctionnent de la même manière.

```mermaid
flowchart LR
    Idea[Idée] --> Draft[Brouillon] --> Review[Relecture] --> Publish[Publication]
    Review -- modifications demandées --> Draft
```

## Champs d'API {#api-fields}

<ParamField path="user_id" type="string" required>
  L'ID de l'utilisateur. Les paramètres de chemin, les paramètres de requête, les en-têtes et les champs du corps ont chacun leur propre variante.
</ParamField>

<ParamField query="limit" type="integer" default="10">
  Nombre maximal de résultats.
</ParamField>

<ResponseField name="user" type="object" required>
  L'objet utilisateur.

  <Expandable title="propriétés">
    <ResponseField name="name" type="string">Le nom de l'utilisateur.</ResponseField>
    <ResponseField name="plan" type="string" default="free">Le forfait de l'utilisateur.</ResponseField>
  </Expandable>
</ResponseField>
