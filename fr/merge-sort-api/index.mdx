{user.name ? <>Bon retour, <strong>{user.name}</strong>{user.plan ? <> (forfait <strong>{user.plan}</strong>)</> : null}.</> : null} L'API Sort est un petit service FastAPI doté de deux endpoints. L'un vous renvoie une liste triée. L'autre vous montre **comment** la liste a été triée.

<Note>
  Cette API est une démo. Son code se trouve dans le [dépôt merge-sort-api](https://github.com/mintlify-demo/merge-sort-api), et cette documentation dans le [dépôt docs](https://github.com/mintlify-demo/docs/tree/main/merge-sort-api).
</Note>

## En un coup d'œil {#at-a-glance}

test

| Endpoint | Méthode | Rôle |
| --- | --- | --- |
| `/sort` | `POST` | Trier une liste de nombres, par ordre croissant ou décroissant |
| `/sort/steps` | `POST` | Idem, avec en plus chaque étape de partition |

<Tip>
  Chaque page d'endpoint dispose d'un playground **Try it**. Pointez-le vers `http://localhost:8000` pendant que l'API tourne.
</Tip>
