<Update label="Novembre 2026" description="Sort API v2.0.0" tags={["API", "Changement incompatible"]}>
  ## Merge Sort API devient Sort API

  `POST /sort` et `POST /sort/steps` utilisent désormais le tri rapide (quick sort) au lieu du tri fusion. Le tri rapide s'exécute en O(n log n) en moyenne et en O(n^2) dans le pire cas.

  <Warning>
    Changement incompatible : chaque élément du tableau `steps` renvoyé par `POST /sort/steps` est désormais une étape de partition avec `pivot`, `before`, `equal` et `after`. Les champs `left`, `right` et `merged` n'existent plus.
  </Warning>

  ```json
  { "step": 1, "pivot": 2, "before": [1], "equal": [2], "after": [4, 3] }
  ```

  Consultez [le fonctionnement du tri rapide](/merge-sort-api/guides/how-it-works) pour lire les nouvelles étapes.

  ### Choisir un algorithme de tri

  `POST /sort` accepte un champ facultatif `algorithm` : `quick` (par défaut), `merge` (stable) ou `heap`. La réponse renvoie `algorithm`. Les valeurs inconnues renvoient `422`. `POST /sort/steps` utilise toujours `quick`.

  ```bash
  curl -X POST http://localhost:8000/sort \
    -H "Content-Type: application/json" \
    -d '{"numbers": [5, 2, 9, 1], "algorithm": "merge"}'
  ```
</Update>

<Update label="Octobre 2026" description="v1.0.0" tags={["Lancement", "Docs"]}>
  ## L'organisation de démo Mintlify est en ligne

  Cinq dépôts, un seul site de documentation.

  - **Quatre API d'exemple** avec FastAPI : Merge Sort, Calculator, Todo et Text Utils
  - **Des références d'API interactives** générées à partir du fichier OpenAPI de chaque API
  - **Une documentation multi-dépôts** : la documentation de chaque API vit dans son propre dépôt
  - **Des pages vitrines** pour les composants et les fonctionnalités IA

  <Check>
    Chaque endpoint a un playground et des exemples de code.
  </Check>
</Update>

<Update label="Octobre 2026" description="Calculator API v2" tags={["API"]}>
  ## `POST /v2/calculate`

  Un seul endpoint qui prend une `operation` et au moins deux `operands`.

  ```bash
  curl -X POST http://localhost:8000/v2/calculate \
    -H "Content-Type: application/json" \
    -d '{"operation": "add", "operands": [1, 2, 3]}'
  ```

  La v1 ne change pas et reste prise en charge.
</Update>

<Update label="Octobre 2026" description="Todo API" tags={["API", "Obsolète"]}>
  ## `GET /todos/list-all` est obsolète

  Utilisez `GET /todos` avec `page` et `page_size`. L'ancien endpoint fonctionne toujours, mais il est marqué obsolète dans la référence d'API.
</Update>
