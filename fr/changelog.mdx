<Update label="Octobre 2026" description="v1.0.0" tags={["Lancement", "Documentation"]}>
  ## L'organisation de démo Mintlify est en ligne {#the-mintlify-demo-org-is-live}

  Cinq dépôts, un seul site de documentation.

  - **Quatre API d'exemple** construites avec FastAPI : Merge Sort, Calculator, Todo et Text Utils
  - **Références d'API interactives** générées à partir du fichier OpenAPI versionné de chaque API
  - **Documentation multi-dépôts** : la documentation de chaque API se trouve dans son propre dépôt
  - **Pages de démonstration** pour les composants et les fonctionnalités d'IA

  <Check>
    Chaque endpoint dispose d'un bac à sable et d'exemples de code.
  </Check>
</Update>

<Update label="Octobre 2026" description="Calculator API v2" tags={["API"]}>
  ## `POST /v2/calculate` {#post-/v2/calculate}

  Un endpoint unique qui accepte une `operation` et deux `operands` ou plus.

  ```bash
  curl -X POST http://localhost:8000/v2/calculate \
    -H "Content-Type: application/json" \
    -d '{"operation": "add", "operands": [1, 2, 3]}'
  ```

  La v1 est inchangée et toujours prise en charge.
</Update>

<Update label="Octobre 2026" description="Todo API" tags={["API", "Obsolescence"]}>
  ## `GET /todos/list-all` est obsolète {#get-/todos/list-all-is-deprecated}

  Utilisez plutôt `GET /todos` avec `page` et `page_size`. L'ancien endpoint fonctionne toujours, mais il est marqué comme obsolète dans la référence d'API.
</Update>

<Update label="Octobre 2026" description="Text Utils API" tags={["API"]}>
  ## Exemples de code en Go {#code-samples-in-go}

  Chaque endpoint affiche désormais des exemples en cURL, Python, JavaScript et Go, rédigés avec `x-codeSamples` dans la spécification OpenAPI.
</Update>
