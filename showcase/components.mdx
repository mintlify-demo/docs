## Diagrams with Mermaid

Write a fenced `mermaid` block and Mintlify renders it, in light and dark mode.

```mermaid
sequenceDiagram
    participant Reader
    participant Docs as Mintlify docs
    participant API as Your API
    Reader->>Docs: Opens an endpoint page
    Docs->>Reader: Shows request builder and code samples
    Reader->>API: Clicks "Try it"
    API-->>Reader: 200 OK with JSON
```

```mermaid
flowchart LR
    Idea --> Draft --> Review --> Publish
    Review -- changes requested --> Draft
```
