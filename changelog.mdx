<Update label="October 2026" description="Sort API v2.0.0" tags={["API", "Breaking change"]}>
  ## Quick sort replaces merge sort

  The Merge Sort API is now the **Sort API**. Both endpoints sort with quick sort instead of merge sort. Quick sort runs in O(n log n) time on average and O(n²) in the worst case.

  `POST /sort` keeps the same request and response. `POST /sort/steps` now returns **partition** steps instead of merge steps. Each step has these fields:

  - `pivot`: the middle item that the list was split around
  - `before`: items that sort before the pivot, still unsorted
  - `equal`: items equal to the pivot
  - `after`: items that sort after the pivot, still unsorted

  The `left`, `right`, and `merged` fields are removed. If your client reads them, update it to read the new fields.

  ```bash
  curl -X POST http://localhost:8000/sort/steps \
    -H "Content-Type: application/json" \
    -d '{"numbers": [4, 3, 2, 1]}'
  ```

  ```json
  {
    "result": [1, 2, 3, 4],
    "count": 4,
    "order": "asc",
    "steps": [
      { "step": 1, "pivot": 2, "before": [1], "equal": [2], "after": [4, 3] },
      { "step": 2, "pivot": 3, "before": [], "equal": [3], "after": [4] }
    ]
  }
  ```
</Update>

<Update label="October 2026" description="Calculator API v2" tags={["API"]}>
  ## `POST /v2/calculate`

  A single endpoint that takes an `operation` and two or more `operands`.

  ```bash
  curl -X POST http://localhost:8000/v2/calculate \
    -H "Content-Type: application/json" \
    -d '{"operation": "add", "operands": [1, 2, 3]}'
  ```

  v1 is unchanged and still supported.
</Update>

<Update label="October 2026" description="Todo API" tags={["API", "Deprecation"]}>
  ## `GET /todos/list-all` is deprecated

  Use `GET /todos` with `page` and `page_size` instead. The old endpoint still works but is marked deprecated in the API reference.
</Update>
