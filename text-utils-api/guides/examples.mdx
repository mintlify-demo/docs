  <Tab title="Reverse">
    ```json Request to /reverse
    { "text": "stressed" }
    ```

    ```json Response
    { "original": "stressed", "reversed": "desserts" }
    ```
  </Tab>

  <Tab title="Word count">
    ```json Request to /word-count
    { "text": "Hello\nhello world" }
    ```

    ```json Response
    { "words": 3, "unique_words": 2, "characters": 17, "lines": 2 }
    ```

    <Note>
      `unique_words` ignores case, so `Hello` and `hello` count once.
    </Note>
  </Tab>

  <Tab title="Palindrome">
    ```json Request to /palindrome
    { "text": "Racecar" }
    ```

    ```json Response
    { "is_palindrome": true, "text": "Racecar" }
    ```
  </Tab>

  <Tab title="Slugify">
    ```json Request to /slugify
    { "text": "Héllo, Mintlify Docs!" }
    ```

    ```json Response
    { "original": "Héllo, Mintlify Docs!", "slug": "hello-mintlify-docs" }
    ```

    <Note>
      Accents are removed (`é` becomes `e`). Anything that isn't a letter or digit is dropped.
    </Note>
  </Tab>

## Strict palindrome mode

By default `/palindrome` ignores case, spaces and punctuation. Turn that off with `ignore_case_and_punctuation`:

<ParamField body="ignore_case_and_punctuation" type="boolean" default="true">
  When `false`, `Racecar` is **not** a palindrome (capital R) but `racecar` is.
</ParamField>

## Slug options

Use `/slugify` to build URL paths, file names, or IDs from titles. By default, words are joined with `-` and the slug has no length limit. Change that with two optional fields:

<ParamField body="separator" type="string" default="-">
  Character placed between words. Must be `-` or `_`. Any other value returns a `422`.
</ParamField>

<ParamField body="max_length" type="integer">
  Maximum slug length, from `1` to `200`. Longer slugs are cut, and any trailing separator is removed.
</ParamField>

```json Request to /slugify
{ "text": "Getting started with Mintlify docs", "separator": "_", "max_length": 20 }
```

```json Response
{ "original": "Getting started with Mintlify docs", "slug": "getting_started_with" }
```

<AccordionGroup>
  <Accordion title="What counts as a word?">
    Runs of letters, digits, apostrophes and hyphens. `don't` and `well-known` are one word each.
  </Accordion>
  <Accordion title="What's the size limit?">
    10,000 characters per request. Longer text returns a `422`.
  </Accordion>
</AccordionGroup>
