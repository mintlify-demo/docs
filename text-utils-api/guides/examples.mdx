  <Tab title="Word count">
    ```json Request to /word-count
    { "text": "Hello\nhello world" }
    ```

    ```json Response
    { "words": 3, "unique_words": 2, "characters": 17, "lines": 2 }
    ```

    <Note>
      `unique_words` ignores case, so `Hello` and `hello` count once.
    </Note>

## Strict palindrome mode

By default `/palindrome` ignores case, spaces and punctuation. Turn that off with `ignore_case_and_punctuation`:

<ParamField body="ignore_case_and_punctuation" type="boolean" default="true">
  When `false`, `Racecar` is **not** a palindrome (capital R) but `racecar` is.
</ParamField>

## Slug options

`/slugify` lowercases the text, removes accents (`é` becomes `e`), and drops anything that isn't a letter or digit. Use these optional fields to control the output:

<ParamField body="separator" type="string" default="-">
  Character placed between words. Must be `-` or `_`. Any other value returns a `422`.
</ParamField>

<ParamField body="max_length" type="integer">
  Maximum slug length, from `1` to `200`. The API cuts longer slugs to this length and removes any trailing separator.
</ParamField>

```json Request to /slugify
{ "text": "The quick brown fox", "separator": "_", "max_length": 10 }
```

```json Response
{ "original": "The quick brown fox", "slug": "the_quick" }
```

<AccordionGroup>
  <Accordion title="What counts as a word?">
    Runs of letters, digits, apostrophes and hyphens. `don't` and `well-known` are one word each.
  </Accordion>
  <Accordion title="What's the size limit?">
    10,000 characters per request. Longer text returns a `422`.
  </Accordion>
</AccordionGroup>
