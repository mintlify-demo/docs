Run the Todo API on your own machine to try changes before you call the hosted API.

## Start the server

<Steps>
  <Step title="Install the dependencies">
    ```bash
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Start the server">
    ```bash
    python serve.py
    ```
    The server listens on `127.0.0.1` port `8000` and reloads when you change the code. To use another port, set `PORT`:
    ```bash
    PORT=9000 python serve.py
    ```
    Set `HOST` to listen on another interface. `uvicorn main:app --reload` also starts the server on port `8000`.
  </Step>
  <Step title="Check that it's running">
    ```bash
    curl http://localhost:8000/todos -H "X-API-Key: demo-key"
    ```
  </Step>
</Steps>

<Tip>
  Use the `demo-key` API key while you test. See [Authentication](/todo-api/guides/authentication) for the other demo keys.
</Tip>
