This policy takes effect on December 1, 2026.

## Uptime

The Todo API targets **99.9% monthly uptime** for all `/todos` endpoints.

Check current status and past incidents on the [status page](https://status.mintlify-demo.example.com).

## Get support

Email [support@mintlify-demo.example.com](mailto:support@mintlify-demo.example.com).

When you report a problem with a request, include the `X-Request-ID` response header from the failing request.

## Response times

| Priority | First response |
| --- | --- |
| Urgent (the API is down) | Within 1 hour, 24/7 |
| High | Within 4 business hours |
| Normal | Within 1 business day |

## Planned maintenance

Planned maintenance is announced on the [status page](https://status.mintlify-demo.example.com) at least 72 hours ahead.

Maintenance is never scheduled on weekdays between 9am and 6pm Pacific.
