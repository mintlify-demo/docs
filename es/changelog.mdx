<Update label="Noviembre de 2026" description="Sort API v2.0.0" tags={["API", "Cambio incompatible"]}>
  ## Merge Sort API ahora es Sort API

  `POST /sort` y `POST /sort/steps` ahora usan quick sort en lugar de merge sort. Quick sort tarda O(n log n) en promedio y O(n^2) en el peor caso.

  <Warning>
    Cambio incompatible: cada elemento del array `steps` de `POST /sort/steps` ahora es un paso de partición con `pivot`, `before`, `equal` y `after`. Los campos `left`, `right` y `merged` ya no existen.
  </Warning>

  ```json
  { "step": 1, "pivot": 2, "before": [1], "equal": [2], "after": [4, 3] }
  ```

  Consulta [cómo funciona quick sort](/merge-sort-api/guides/how-it-works) para leer los nuevos pasos.
</Update>

<Update label="Octubre de 2026" description="v1.0.0" tags={["Lanzamiento", "Docs"]}>
  ## La organización de demo de Mintlify ya está disponible

  Cinco repositorios, un sitio de documentación.

  - **Cuatro APIs de ejemplo** con FastAPI: Merge Sort, Calculator, Todo y Text Utils
  - **Referencias de API interactivas** generadas desde el archivo OpenAPI de cada API
  - **Documentación multirrepositorio**: la documentación de cada API vive en su propio repositorio
  - **Páginas de muestra** de componentes y funciones de IA

  <Check>
    Cada endpoint tiene un playground y ejemplos de código.
  </Check>
</Update>

<Update label="Octubre de 2026" description="Calculator API v2" tags={["API"]}>
  ## `POST /v2/calculate`

  Un solo endpoint que recibe una `operation` y dos o más `operands`.

  ```bash
  curl -X POST http://localhost:8000/v2/calculate \
    -H "Content-Type: application/json" \
    -d '{"operation": "add", "operands": [1, 2, 3]}'
  ```

  La v1 no cambia y sigue siendo compatible.
</Update>

<Update label="Octubre de 2026" description="Todo API" tags={["API", "Obsoleto"]}>
  ## `GET /todos/list-all` está obsoleto

  Usa `GET /todos` con `page` y `page_size`. El endpoint antiguo sigue funcionando, pero aparece como obsoleto en la referencia de API.
</Update>
