## El asistente {#the-assistant}

El asistente responde preguntas sobre tu documentación y tu API, cita las páginas que usó y escribe código que se puede copiar.

<Steps>
  <Step title="Ábrelo">
    Pulsa <kbd>⌘</kbd> + <kbd>I</kbd> (o <kbd>Ctrl</kbd> + <kbd>I</kbd>), o haz clic en **Ask AI** en la barra de búsqueda.
  </Step>
  <Step title="Pregunta algo real">
    Prueba estas preguntas en este sitio:

    - *¿Cómo me autentico con la Todo API?*
    - *Escribe un script de Python que recorra todas las páginas de tareas.*
    - *¿Cuál es la diferencia entre la Calculator API v1 y v2?*
  </Step>
  <Step title="Revisa las fuentes">
    Cada respuesta enlaza a las páginas de las que proviene. También lee las especificaciones OpenAPI, así que conoce los parámetros y las respuestas de cada endpoint.
  </Step>
</Steps>

<Note>
  El asistente está incluido en los planes Pro y Enterprise. Actívalo y ajústalo en el panel de Mintlify.
</Note>

## llms.txt y llms-full.txt {#llms-txt-and-llms-full-txt}

Mintlify genera dos archivos para cada sitio, de forma automática:

| Archivo | Qué contiene |
| --- | --- |
| `/llms.txt` | Un índice breve: cada página con su título y descripción |
| `/llms-full.txt` | El texto completo de la documentación en un solo archivo |

Agrega `.md` a la URL de cualquier página, o usa **View as Markdown** en el menú contextual, para obtener una versión limpia en Markdown solo de esa página. Los agentes obtienen el mismo contenido que ven las personas, sin los elementos de la interfaz de la página.

<Tip>
  En este sitio, prueba `/llms.txt` y `/quickstart.md` en tu navegador.
</Tip>

## Servidor MCP {#mcp-server}

Tu sitio obtiene un **servidor MCP** alojado en `/mcp`, sin configuración. Una herramienta de IA que se conecte a él puede buscar en tu documentación y leer páginas completas mientras trabaja.

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http mintlify-demo https://YOUR-DOCS-DOMAIN/mcp
    ```
  </Tab>
  <Tab title="Cursor">
    Usa **Connect to Cursor** en el menú contextual de cualquier página.
  </Tab>
  <Tab title="Cualquier cliente MCP">
    Agrega la URL `https://YOUR-DOCS-DOMAIN/mcp` como servidor MCP HTTP.
  </Tab>
</Tabs>

<Info>
  Reemplaza `YOUR-DOCS-DOMAIN` por el dominio de este sitio.
</Info>

## skill.md {#skill-md}

Mintlify también aloja un `skill.md` en la raíz de tu sitio. Sigue el formato de [agentskills.io](https://agentskills.io/specification) y describe lo que un agente puede hacer con tu producto, qué entradas necesita y a qué debe prestar atención. Instálalo en un agente con:

```bash
npx skills add https://YOUR-DOCS-DOMAIN
```

<Note>
  Mintlify genera `skill.md` por ti, y puede tardar hasta 24 horas después de la primera publicación. Para escribir el tuyo, agrega un archivo `skill.md` en la raíz del repositorio.
</Note>

## Menú contextual {#contextual-menu}

El menú junto al título de cada página se configura en `docs.json` con `contextual.options`. Este sitio activa 17 opciones, entre ellas:

<Columns cols={2}>
  <Card title="Copiar página" icon="copy">Copia la página como Markdown.</Card>
  <Card title="Ver como Markdown" icon="markdown">Abre la versión `.md`.</Card>
  <Card title="Abrir en ChatGPT, Claude, Perplexity, Grok" icon="arrow-up-right-from-square">Inicia un chat con la página como contexto.</Card>
  <Card title="Conectar MCP a Cursor o VS Code" icon="plug">Instalación del servidor MCP con un clic.</Card>
</Columns>

```json docs.json
{
  "contextual": {
    "options": [
      "copy", "view", "assistant", "chatgpt", "claude", "perplexity", "grok", "aistudio", "devin",
      "windsurf", "mcp", "cursor", "vscode", "devin-mcp", "add-mcp", "download-spec", "download-pdf"
    ]
  }
}
```

El componente `Visibility` muestra contenido diferente según quién esté leyendo.
