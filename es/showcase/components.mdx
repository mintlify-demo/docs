## Diagramas con Mermaid {#diagrams-with-mermaid}

Escribe un bloque delimitado `mermaid` y Mintlify lo renderiza, en modo claro y oscuro.

```mermaid
sequenceDiagram
    participant Reader as Lector
    participant Docs as Documentación de Mintlify
    participant API as Tu API
    Reader->>Docs: Abre una página de endpoint
    Docs->>Reader: Muestra el generador de solicitudes y ejemplos de código
    Reader->>API: Hace clic en "Try it"
    API-->>Reader: 200 OK con JSON
```

Los diagramas de flujo funcionan de la misma manera.

```mermaid
flowchart LR
    Idea[Idea] --> Draft[Borrador] --> Review[Revisión] --> Publish[Publicación]
    Review -- cambios solicitados --> Draft
```

## Campos de API {#api-fields}

<ParamField path="user_id" type="string" required>
  El ID del usuario. Los parámetros de ruta, los parámetros de consulta, los encabezados y los campos del cuerpo tienen cada uno su propia variante.
</ParamField>

<ParamField query="limit" type="integer" default="10">
  Número máximo de resultados.
</ParamField>

<ResponseField name="user" type="object" required>
  El objeto de usuario.

  <Expandable title="propiedades">
    <ResponseField name="name" type="string">El nombre del usuario.</ResponseField>
    <ResponseField name="plan" type="string" default="free">El plan del usuario.</ResponseField>
  </Expandable>
</ResponseField>
