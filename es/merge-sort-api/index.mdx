{user.name ? <>Hola de nuevo, <strong>{user.name}</strong>{user.plan ? <> (plan <strong>{user.plan}</strong>)</> : null}.</> : null} La API de Merge Sort es un pequeño servicio de FastAPI con tres endpoints. Uno te devuelve una lista ordenada. Otro te muestra **cómo** se ordenó la lista. El tercero compara la rapidez de cada algoritmo de ordenación con tu lista.

<Note>
  Esta API es una demo. Su código está en el [repositorio merge-sort-api](https://github.com/mintlify-demo/merge-sort-api), y esta documentación está en el [repositorio docs](https://github.com/mintlify-demo/docs/tree/main/merge-sort-api).
</Note>

## De un vistazo {#at-a-glance}

test

| Endpoint | Método | Propósito |
| --- | --- | --- |
| `/sort` | `POST` | Ordenar una lista de números, de forma ascendente o descendente |
| `/sort/steps` | `POST` | Lo mismo, más cada paso de fusión |
| `/sort/stats` | `POST` | Medir quick sort, merge sort y heap sort con la misma lista, del más rápido al más lento |

<Tip>
  Cada página de endpoint tiene un playground **Try it**. Apúntalo a `http://localhost:8000` mientras la API esté en ejecución.
</Tip>
