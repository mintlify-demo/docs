## Endpoints {#endpoints}

| Método | Ruta | Qué hace |
| --- | --- | --- |
| `GET` | `/todos` | Lista las tareas (paginado, filtrable) |
| `POST` | `/todos` | Crea una tarea |
| `GET` | `/todos/{todo_id}` | Obtiene una tarea |
| `PATCH` | `/todos/{todo_id}` | Actualiza una tarea |
| `DELETE` | `/todos/{todo_id}` | Elimina una tarea |
| `GET` | `/todos/list-all` | <Badge color="orange">Obsoleto</Badge> Lista todas las tareas, sin paginar |
| `POST` | `/todos/bulk` | <Badge color="purple">Enterprise</Badge> Crea hasta 100 tareas a la vez |
| `POST` | `/graphql` | Consultas y mutaciones de GraphQL |
| `WS` | `/ws/events` | Flujo de `todo.created`, `todo.updated`, `todo.deleted` |

<Warning>
  Los datos se guardan en memoria. Reiniciar el servidor borra todas las tareas.
</Warning>
