Ejecuta la Todo API en tu propia máquina para probar cambios antes de llamar a la API alojada.

## Inicia el servidor {#start-the-server}

<Steps>
  <Step title="Instala las dependencias">
    ```bash
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Inicia el servidor">
    ```bash
    uvicorn main:app --reload
    ```
    El servidor escucha en el puerto `8080`.
  </Step>
  <Step title="Comprueba que esté en ejecución">
    ```bash
    curl http://localhost:8080/todos -H "X-API-Key: demo-key"
    ```
  </Step>
</Steps>

<Tip>
  Usa la clave de API `demo-key` mientras haces pruebas. Consulta [Autenticación](/es/todo-api/guides/authentication) para ver las otras claves de demostración.
</Tip>
