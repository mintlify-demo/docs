Ejecuta la Todo API en tu propia máquina para probar cambios antes de llamar a la API alojada.

## Iniciar el servidor {#start-the-server}

<Steps>
  <Step title="Instala las dependencias">
    ```bash
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Inicia el servidor">
    ```bash
    python serve.py
    ```
    El servidor escucha en `127.0.0.1`, en el puerto `8000`, y se recarga cuando cambias el código. Para usar otro puerto, establece `PORT`:
    ```bash
    PORT=9000 python serve.py
    ```
    Establece `HOST` para escuchar en otra interfaz. `uvicorn main:app --reload` también inicia el servidor en el puerto `8000`.
  </Step>
  <Step title="Comprueba que está en ejecución">
    ```bash
    curl http://localhost:8000/todos -H "X-API-Key: demo-key"
    ```
  </Step>
</Steps>

<Tip>
  Usa la clave de API `demo-key` mientras haces pruebas. Consulta [Autenticación](/es/todo-api/guides/authentication) para ver las demás claves de demo.
</Tip>
